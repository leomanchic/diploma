# Замороженный протокол проверки подтверждения трека

Статус: зафиксирован **до новых оценочных аудиозапусков**. База:
`e85bc51bcdb843e8f4ed7073ee1bae30a3dd1429`; ветка
`feature/robust-track-confirmation`. Старые восемь случаев — только разработка
и регрессия. Они не входят в независимую оценку нового варианта.

## Единственный opt-in вариант

Baseline использует полный снимок `processing` опубликованного range study.
Новый вариант отличается ровно одним полем
`tracker.recovery.confirmation_station_count: 2 -> 3`. Он требует, чтобы
последующие доступные и согласованные с tentative-гипотезой события от всех
трёх станций сохранились и после окончательного consensus refit. Используются
существующие ретардированные предсказания для собственного времени излучения
каждой станции. Дополнительного оптимизатора и отдельной копии confirmation
не вводится. Число требуемых событий остаётся 3, reception span 0,05 s,
fit-NIS threshold 10,596634733096073, maximum confirmation age 3 s,
maximum confirmation events 180, failures 20. Все остальные thresholds,
construction 6, candidates 16, hypotheses 8, history, Qc, R, bias, акустика,
геометрия и budget 128 сохранены. Любая новая попытка consensus refit входит
в этот бюджет; runtime и peak history memory измеряются.

Опция выбирается для всего запуска, без доступа к сценарию, координатам или
ошибке. Слабая радиальная наблюдаемость сама по себе не служит основанием для
отбрасывания измерения. При выключенной опции используется неизменённая
baseline конфигурация.

## Контрольные аудиопотоки

12 потоков: `single_turn` и `opposite_turns` из исходных записей PX4/Gazebo,
начальные дальности 200, 700, 1000 m, по две новые реализации шума на пару
траектория/дальность. Сигнал каждого движения — прежний сохранённый source
bank; модель `1/r`, фиксированный фон, SNRref=10 dB, 48 kHz аудио, прежние
frame/hop/stride и параметры обработки. Фиксированный root seed новых
реализаций: `20260927`; вычисление каждого noise seed —
`SeedSequence([20260927, trajectory_index, replicate_index]).generate_state(1,
dtype=uint64)[0]`. Порядок траекторий: single_turn=0, opposite_turns=1.
Seeds по траекториям и replicate: `2279586615842805297`,
`6929539839069591369`, `2191817683501416574`, `6674498936964276922`.
Один noise seed повторяется на трёх дальностях, сохраняя парность; все четыре
отличны от прежних реализаций. Baseline и opt-in получают побайтово одни и
те же сохранённые bearing events. Для каждого из 12 потоков два метода и два
варианта: 48 tracker replays. Исторические `run_id` не переиспользуются.

## Метрики и правило решения

Для каждого метода и варианта: 12 потоков в знаменателе доли хотя бы одного
подтверждения; время первого подтверждения и ошибка позиции/скорости при нём
по подтверждённым с явным числом; severe confirmation >50 m по **всем 12**
(отказы считаются отдельно); radial/transverse ошибки; valid/confirmed
availability по всем публикациям; conditional RMSE/P95 вместе с долей
доступности; отказы, updates и их причины; batch fit count, wall runtime,
peak history memory; position/state NEES и nominal coverage с явным числом
валидных публикаций. Пары сравниваются по целым аудиопотокам, кадры не
считаются независимыми испытаниями. Номинальный covariance ellipsoid не
является эмпирической гарантией.

«Улучшение подтверждено в ограниченном протоколе» только если по 24
method-stream парам число severe confirmations уменьшается не менее чем на 2,
число любых подтверждений падает не более чем на 2, общая confirmed
availability падает не более чем на 0,10 абсолютной доли, а медианное время
первого подтверждения среди общих подтверждённых пар увеличивается не более
чем на 1,0 s. При уменьшении severe count без выполнения этих ограничений
итог — «обнаружен компромисс». В остальных случаях — «улучшение не
подтверждено». Успешное подтверждение не считается доказательством точной
локализации или увеличения дальности. Устойчивый P99 и редкие отказы по 12
потокам не оцениваются.

Тесты и отчёт строятся после сохранения всех событий. Параметры после
просмотра контрольных результатов не меняются. Старый range study, полёты,
Monte Carlo и старые notebooks не запускаются.
